# CZK CPI forecasting — R17 results and model map

The full approved experiment is complete. Most additions did not improve the forecasts. The strongest useful findings are narrower: shared autoregression helps forecast a covered services-price proxy; annual-index fuel conditioning helps some recent headline forecasts; and the policy audit corrects several source and accounting assumptions. There is no demonstrated new all-purpose replacement for the existing path models.

Open the [CNB Rounds Replayed artifact](output/research_r17/path/evaluation/cnb_rounds_replayed_r17.html). It retains the original layout, with all 30 models selectable, both historical clocks, monthly h0–h12 paths, realised inflation and the published CNB quarterly paths. Visibility does not change the score sample. The last frozen origin is **July 2026**; this is a historical research replay, not a live September forecast.

The independent next-release nowcast is unchanged. Every new path retains the same HARD_BASE h0. No survey, inflation expectation, confidence series or CNB forecast was added to the new independent models. This experiment therefore provides no new evidence of beating next-release market consensus: its new performance results concern the path after h0.

## Headline improvement still needs a component explanation

On the same 75 full-history h12 observations, cumulative core log-error RMSE is 4.2785 for FAST, 4.6636 for robust core and 4.7841 for repeated-news core. Recent values are 0.5865, 1.1544 and 1.5505. Their lower headline RMSE therefore cannot be described as better standalone core forecasting. As in R16, retained component errors and aggregation can make a poorer core forecast improve the total.

The food experiment has no compelling standalone winner. On 1,002 common realised monthly food observations, FAST RMSE is 1.1381, symmetric costs 1.1686 and asymmetric costs 1.1847. The asymmetric split does not uncover a dependable improvement just because rising and falling agricultural costs are economically different. [Full food report](work/research_r17_food/R17_FOOD_RESULTS_2026-09-14.md).

The monthly-category test produces a useful intermediate result. The covered pressure proxy's monthly RMSE falls from 0.5673 with persistence to 0.5307 with shared AR. Adding domestic variables gives 0.5864, imported variables 0.6457, and both 0.6785. Passing the saved forecasts into core does not improve the final core forecast: pooled monthly core RMSE is 0.43279 for FAST versus 0.43567 for generated AR and 0.43663 for generated both. [Full monthly-category report](work/research_r17_monthly/R17_MONTHLY_RESULTS_2026-09-14.md).

These five categories are actual rent, imputed rent, catering, accommodation and package holidays. They are national, tax-including service-price series with dated basket weights. They are not an exact tax-adjusted core partition. The weighted pressure index and core-minus-pressure reconciliation difference are explicitly labelled statistical diagnostics. No annual goods series was misrepresented as monthly goods inflation.

Fuel also illustrates why both layers matter. Over 78 available h12 component outcomes, annual-index conditioning improves cumulative fuel log RMSE from 17.1193 to 16.4652. Over 19 recent origins it worsens from 11.7816 to 13.1632, despite improving recent headline RMSE. Its recent mean absolute fuel error improves while its squared error worsens. That is a mixed result, not evidence of a universally better fuel mechanism. [Component scores](output/research_r17/path/evaluation/component_scoreboard.csv).

Perfect-information replacements show where errors matter, not what a feasible model will achieve. For the 19 recent h12 FAST forecasts, headline RMSE 0.858 falls to 0.521 with realised food substituted, 0.608 with realised administered prices, and 0.401 when all noncore components are replaced jointly. Replacing only fuel actually increases it to 1.046. The model has offsetting component errors; adding individual oracle gains would be wrong. [Attribution](output/research_r17/attribution/primary_oracle_summary.csv).

## What the h0 and combination tests mean

Every path already uses the independent h0 headline forecast when compounding annual CPI. The new h0 experiment additionally asks whether the independent **core** nowcast should change future core dynamics.

It uses the saved own-origin raw core forecast, subtracts the same origin's state-only prediction, and learns its incremental value from previously published core forecast errors. This avoids treating two overlapping-information estimates as independent observations. The mean learned coefficient is about 0.33. The state covariance is not presented as an updated calibrated posterior.

That extra propagation did not help. FAST+h0 has recent h12 headline RMSE 0.8952 versus FAST 0.8580; NEWS+h0 has 0.8828 versus NEWS 0.8425. A useful next-release estimate can contain temporary information that should not be carried into the persistent path with the tested state mapping. Retain the existing h0 anchor; reject this additional future-core update as an operating change.

The whole-path selectors use no outer future labels. For each historical origin, they compare saved candidate paths only after all 12 future monthly outcomes have matured and been published. A single weight vector applies across the entire monthly path. The pool requires at least half FAST and caps each alternative at one quarter. Its objective is whole-path annual-CPI squared error plus a fixed small concentration penalty, with a 12-origin minimum and latest 36 validation origins.

The component-correction selector chose unchanged FAST in 83 of 90 origins. The broader pool chose pure FAST 28 times and mixtures otherwise; its latest frozen choice is also pure FAST. Both selectors default to FAST when historical validation is insufficient. Fully matured 12-month validation necessarily reacts slowly to a new regime; these conservative weights did not solve that tradeoff. [Saved selections and training dates](output/research_r17/path/selections.json).

## CNB comparisons and meaningful large deviations

These scores average monthly annual-CPI forecasts into complete quarters from one selected origin. They are different targets/calendars from the monthly h12 table. Both original report and information-cutoff clocks remain available; neither was chosen to improve a result.

On the report clock, 66 forecast-quarter/report pairs from 18 reports and 18 distinct target quarters give:

| Model | MAE | RMSE | Material gains / losses vs CNB |
|---|---:|---:|---:|
| CNB | 1.0605 | 2.2955 | — |
| FAST | 1.2597 | 1.9867 | 15 / 32 |
| Repeated-news core | 1.2193 | 1.8350 | 11 / 35 |
| Robust core | 1.2486 | 1.9129 | 13 / 29 |
| Annual-index fuel | 1.2239 | 2.0276 | 17 / 27 |
| Constrained pool | 1.2757 | 2.0210 | 17 / 31 |

A material win requires at least 0.15 pp lower absolute error; losses use the same threshold. A forecast merely on the correct side of CNB gets no automatic win. The broad pattern remains lower squared error on a few large misses but worse average absolute error and more material losses than gains.

Omitting the February 10, 2022 report reverses the apparent RMSE advantage: repeated-news core 1.6601, robust 1.6931 and FAST 1.7391 versus CNB 1.4763. This is one report omitted from the same fixed comparisons; no forecasts were refitted. [Both-clock scoreboard](output/research_r17/path/evaluation/cnb_summary.csv), [every-report omissions](output/research_r17/path/evaluation/cnb_leave_one_report_out.csv).

For your large-deviation objective, we also condition on CNB absolute errors of at least 0.5 pp and 1 pp. At the 1 pp threshold, repeated-news core has 9 material gains and 4 losses, with median signed capture 0.361 and average absolute-error improvement 1.306 pp. But those 13 observations all come from **four 2022 reports and six distinct quarters**. They are not 13 independent events and provide no recent-regime validation. [Large-deviation rows and scores](output/research_r17/path/evaluation/cnb_large_departure_summary.csv).

Capture is (model−CNB)/(actual−CNB). Exact capture is 1; opposite direction is negative; overshoot beyond 2 is explicitly counted and loses under absolute-error scoring. Capture does not determine the model ranking. These are CNB **path** forecast errors, not release-survey surprises.

Recent report-clock results are more informative about ordinary conditions: on 34 pairs, annual-index fuel MAE 0.2882 is close to CNB 0.2865, but its RMSE 0.3995 exceeds CNB 0.3718; material gains/losses are 9/7. Current core has MAE 0.2754 and RMSE 0.4019. This is useful comparative evidence, not consistent CNB dominance.

## Turning points remain a weakness

Retaining the old strict core peak/trough definition matters. On 159 common opportunities with 77 actual turns, the new state filters make no material interior-turn calls. Monthly AR makes 17 calls, five correct and 12 false, missing 72 actual turns. More flexible paths can turn, but their additional turns are not reliably right.

The additional sustained-movement diagnostic requires a 0.5 pp annualized change from the first to third core band without a material opposite adjacent movement. On 81 origins with 37 actual events, repeated-news core makes 35 calls but only three correct. The existing residual forest captures 18 events with 54 calls, hence 36 false calls. Greater recall comes with substantial false alarms. This diagnostic does not rescue the state models or establish a usable trading signal. [Strict turns](output/research_r17/path/evaluation/underlying_core_turn_summary.csv), [sustained movements](output/research_r17/path/evaluation/sustained_movement_summary.csv).

## Energy policy corrections and remaining data requirement

The source audit produced 34 event facts, 24 exposure-field assessments, 15 declared scenarios and 23 source records. Corrections include:

- The 2021 VAT CPI-treatment gate is December 10, enabling the known January 2022 expiry afterward. The inverse step is 1.21, not adding back the percentage fall.
- The 2022 saving credit expires in January 2023; POZE relief continues through 2023 and expires in January 2024. They are distinct measures.
- The 2026 zero-POZE amendment is an adopted December 29, 2025 event, not information available from the original November decision. Unknown 2027 policy does not imply automatic reversal.
- POZE needs consistent capacity/volume/billing-period arithmetic. It must not be added again when already included in a total-regulated price change.
- Household/small-user regulated gas growth for 2025 is 8.6%; an 8.2% large-user rate is a different population.
- Today's revised 2022 Eurostat energy averages are not certified historical 2022 vintages. CEZ's mixed-VAT “840” summary and an unsupported national customer-share mapping are rejected.

The [source audit with official links and archived decrees](work/research_r17_policy/R17_POLICY_SOURCE_AUDIT.md) supports these facts. The [working eligibility ledger](output/research_r17_energy/policy_eligibility.csv) returns no national point forecast because it lacks both complete CPI household exposure and an identified embedded baseline energy subpath. This is an explicit operational refusal, not a silent zero shock.

VAT factors, revised-rate replacement, POZE caps, aggregate-credit arithmetic, sample bill sensitivities and start/expiry behavior are implemented and tested. The 27 sample bills use declared quantity/fee/reset assumptions; the prior capacity schedule is explicitly a 2024 carry-forward assumption. They are not scored as national CPI predictions. The high-priority data need is a dated household tariff/contract/cohort portfolio with comparable fixed expenditure denominators and basket treatment, not another fitted January multiplier.

Fuel uses saved origin-specific R14 petrol/diesel ECM coefficients and the original dated petrol share, tax reconciliation and source clocks. Its constant-spot replay matches exactly. New futures scenarios use only eligible historical Bloomberg observations. A log interpolation to the user's annual index is a declared conditioning assumption: exact ticker maturity/roll mapping is not certified, and it is not a recovered monthly futures curve. TTF scenarios remain separate commodity paths until household reset exposure is known. [Quote audit](output/research_r17_energy/quote_audit.csv), [TTF scenarios](output/research_r17_energy/gas_scenarios.csv).

## Small working roster and assessment

Keep the independent nowcast unchanged. For path research, keep FAST as the responsive reference, current core as the recent-period comparison, and the existing gentle R16 slope as a headline sensitivity. Add the annual-index fuel scenario as a transparent conditional comparison. Keep category AR outputs for diagnosis. The 30-row research roster should not become 30 daily operating models.

Do not promote the all-components blend, the selectors, asymmetric food, generated macro-category core paths, or h0 propagation from this batch. Robust core adds little beyond the existing gentle model. Retain all results so a future improvement can be compared against the same evidence rather than rediscovered.

My assessment is that we have a credible, testable independent forecasting framework with useful component and scenario diagnostics. It still lacks reliable advance core-turn prediction, a consistent CNB advantage and a prospective record. Better policy measurement and recorded as-issued inputs/forecasts are now more valuable than a much larger hyperparameter search. Any next path experiment should improve an economically identifiable component and the aggregate on the same dates, with explicit false-alarm costs and a genuinely new validation period.
