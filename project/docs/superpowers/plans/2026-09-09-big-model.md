# Paper-Inspired Big Czech CPI Model Implementation Plan

> **For agentic workers:** implement this plan task by task with tests and review checkpoints.

**Goal:** Prepare a research-only, official-data version of the large paper-inspired Czech CPI model without requiring Bloomberg, while preserving the existing independent nowcast.

**Architecture:** Build a source-agnostic monthly feature layer with three policies: independent hard data, independent plus sentiment, and full paper-style expectations. Fit direct horizon models separately at h1, h3, h6, h9 and h12 using the existing TVW-QRF and BBIM-lite engines, with per-origin freshness filtering and training-only imputation. A runner will load the current CZSO/CNB/Eurostat panel, save release-stamped inputs and forecasts, and compare the new models with AR3, random walk and the existing wide QRF reference.

**Tech Stack:** Python, pandas, NumPy, scikit-learn, quantile-forest, existing `backtest.engine`, `models.horizon_models`, and `models.bbim_lite`.
