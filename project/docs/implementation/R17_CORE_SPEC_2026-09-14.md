# R17 core adaptation and h0 information — prefit specification

Approved scope: Task3 of R17 master plan. No grid search or outcome-based retuning. All source/model outputs from R15/R16 remain unchanged. Forecasts replace only core at h1..12 in FAST's fixed component system; HARD_BASE h0 is preserved.

## Three-state filters

Reuse each historical origin's R15 seasonal vector and released monthly core through t−1. Adjusted rate is100log1p(core_mm/100)−seasonal. State(level,slope,temporary), F=[[1,.95,0],[0,.95,0],[0,0,.8]], H=[1,0,1]. Initialize mean(first12),0,0 and covariance diag(1,.01,1); update observations13 onward. Fixed Q=diag(.05,.001,.20), R=1 exactly reproduces R16 p95_q001.

Two new variants:

- ROBUST: fixed Q; inflate observation disturbance variance for an unusually large standardized innovation.
- NEWS: same robust treatment of isolated innovations, but a sustained same-sign sequence permits a larger trend/slope process variance Q=diag(.20,.01,.20) for that observation.

Standardize each raw innovation e using a scale computed from PREVIOUS innovations only: last36, min12; sigma=max(.05,1.4826*median(abs(e_past−median(e_past)))). Until12 innovations exist, use the same MAD/floor on the first12 adjusted observations. Save each innovation and the scale actually used at its date. Repeated news means current z and previous two saved z have the same nonzero sign and each absolute value>=.5. NEWS uses its larger Q and R=1 on such observations; otherwise R=max(1,(abs(z)/2.5)^2). ROBUST always uses that latter R. Current innovation is computed from F times previous mean; Q/R alter covariance/gain, not that prior mean. Use Joseph covariance update and validate symmetry/PSD.

Forecast t+h with h+1 transitions from the filtered t−1 mean, adding the saved destination seasonal factor. No forecast clipping, new seasonal estimation, survey anchor or future innovation assumption. Q describes fitted state uncertainty; it does not itself change the future point path. Phi=.95 permits interior reversals but no turning skill is presumed.

## Incremental independent h0 signal

Read the archived `policy=hard` core_forecast from output/independent_nowcast_diagnostics.json; verify every row against `R9_BASE` in output/research_r13/nowcast/core_predictions.csv. These are the already issued independent raw core forecasts, not HALF/FULL corrections. No h0 input is reconstructed with a later fit.

For FAST and NEWS separately, save the state-only log-core prediction p0 at every historical origin. For each earlier origin s whose core month is strictly before current t and detail-published by its current clock, form d_s=archived_h0_log_s−p0_s and a_s=actual_core_log_s−p0_s. Use the last60 common rows; require12. Coefficient beta=clip[(sum(a*d)/sum(d²))*n/(n+24),0,1], or0 for fewer12/zero signal variance. This learns the INCREMENTAL value of h0 given the state-only forecast, allowing their errors to share information; it does not assume two independent observations.

At current t, delta=beta*(archived_h0_log−p0). Propagate filtered state to t and map delta into it along w=P0*H/(H*P0*H), so H*w=1; then forecast future h by F^h times the adjusted t-state. P0 uses the fixed/last-known process covariance for the parent filter. Keep state-only covariance unchanged and label it as pre-update covariance: this is a learned conditional-mean correction, NOT a calibrated Bayesian posterior or uncertainty band. Export beta, actual training origins/releases, d,a, effective correction, residual fit RMSE and rejected/default status.

New candidates: CORE_ROBUST_R17, CORE_NEWS_R17, CORE_FAST_H0_R17, CORE_NEWS_H0_R17. Saved R16 gentle slope and R15 FAST/current core remain controls; fixed replay is a numerical check. The h0-conditioned models still retain the original HARD_BASE headline h0 exactly.
