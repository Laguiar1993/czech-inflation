# R15 independent core trend and residual path — declaration and implementation plan

**Goal:** implement the user's approved changing-core-trend plus mean-reverting-residual experiment, with services/import signals, elastic nets, forests and combinations; judge accuracy, direction and CNB-relative paths on fixed clocks.

**Architecture:** a two-state Kalman model decomposes seasonally adjusted monthly log core inflation into a random-walk trend and an AR(1) temporary component. Direct quarterly-band residual models adjust that economic baseline. All new headline paths preserve HARD_BASE h0, and use STABLE_PIPELINE_R14B's fixed food/fuel/admin/alcohol/wedge path; compare on the same origins against that control, the original independent bridge and current-core variant. This is a new research lane, no operating model promotion.

**Tech stack:** offline pandas/numpy/scikit-learn; existing component compounding and historical release masks. Existing isolated checkout, unrelated WIP preserved. User approved the conceptual design in the request; routine details below are frozen before results. No expectation/survey target inputs and no new live source pulls are needed.

## Frozen model specification

- Core target: CNB monthly core from cleanup fixture, beginning 2007. For origin t retain only detailed-published observations through t-1. Log rates are 100*log1p(mm/100). Estimate seasonal effects using the existing own-origin R14 detrended-month method, trailing at most 120 eligible months, normalize sum to zero; require 36 core months. Store every origin's seasonal vector and state separately; later origins cannot rewrite earlier labels.
- State equations: trend random walk; residual AR(1) rho=0.8; observation=trend+residual+noise. Observation R=1 and Q/R ratios define fixed gains independently of inflation units: Qtrend=.01/.05/.20 (slow/default/fast), Qresidual=.20. Initial trend mean of first twelve adjusted observations, initial residual zero, initial covariance diagonal(1,1); filter from observation 13 onward. Forecast at t+h is trend+rho^(h+1)*residual because last observed core is t-1, plus destination seasonality. All three baselines retained; default=.05. No hidden 2% anchor.
- Residual target: for bands h1:3,4:6,7:9,10:12, mean log-core outcome minus the mean of the **saved default filter forecast and seasonal vector at that historical origin**. Future monthly correction is the same residual across each three-month band, keeping that origin's changing seasonal pattern and AR decay. Temporary filter state mean-reverts; learned band departures are direct finite-horizon corrections, not a claim of monotone reversion through h12.
- Own features: filtered trend/residual, adjusted core last month/last3/last12, last3-last12, core seasonal destination-band mean. Domestic signals: broad services y/y and three-month change, a6_11 unemployment and a6_12 SA industrial production changes, a6_17 ULC growth. Imported-cost signals: broad goods y/y and change, EURCZK monthly/three-month log moves, a6_23 German HICP, a6_26 imports, a6_45/47 PPI, a6_56 PPI REER, a6_62 metals; keep current and last3 transforms where stated by feature manifest. Broad goods/services are predictor proxies including their tax/concept differences, not a fabricated exact core partition. Detailed hotels/rents/etc begin only in 2015: report coverage and use broad services as the primary longer-history signal.
- Wide elastic-net: own plus all A6 hard rows except 14/15/16 (re-estimated Rushin/LUCI histories) plus services/goods. No A6 survey/expectation rows. This restriction is experiment-specific, not a reversal of the user's permission to use LUCI elsewhere.
- Four elastic-net feature sets: own+domestic, own+imported, own+both, wide. Standardize using eligible training rows only. Drop all-missing/constant columns, mean-impute from training only and apply those same transforms to the origin. Target standardized by training RMS, without centering; fit_intercept=False so zero residual remains the shrinkage anchor. Include a constant column with penalized coefficient. Alpha=.01/.1/1, l1_ratio=.2/.8, last120 **eligible monthly origins**, minimum48. Six declared configurations per set; default alpha=.1/l1=.2. Max_iter=10000,tol=1e-6, deterministic coordinate descent. Record convergence; fail unavailable rather than silently accept nonconvergence.
- Residual forest: own+both, same labels and last120 training support, 150 trees, max_features=1/3, bootstrap=True, seed42, min_leaf=5/15; default15. Prediction is default state path + learned residual. Missing-data transforms train-only. Trees are bounded in residual support, while the moving trend can shift forecast levels beyond historical total-inflation support.
- Nested chronological selection: each configuration predicts at every historical origin after enough training. At each outer origin/band select from last36 **consecutive available common stored candidate forecast rows** with all band outcomes released before current clock and target month<t. Require24; otherwise fixed default. Minimize prior residual MSE, ties retain declared default then stable order. No current/future result can select its own settings. Baseline filter adaptation uses the same rule on band forecast errors across its three filters.
- Roster: STATE_SLOW/MID/FAST, STATE_ADAPT, ENET_DOMESTIC/IMPORTED/BOTH/WIDE, RF_RESIDUAL, BLEND_LINEAR_RF=(ENET_BOTH+RF)/2, BLEND_WIDE_STATE=(ENET_WIDE+STATE_MID)/2. Average monthly log core forecasts before headline component aggregation. No retrospectively optimized mixture weights. Keep all models including failures in the coverage ledger.

Pre-fit input clarification: the consumed panel is `paper_model_panel_20260912_luci`, whose row17 is the Bloomberg LCTQCZI nominal ULC per-person NSA **index level**, not the exact-panel CNB SA annual rate. Its growth feature is 100log(latest available index/index available12 snapshots earlier); IP growth similarly uses the SA index versus3 snapshots earlier. The loader asserts that source concept. Rows65/66 in the inherited paper panel are shifted twelve rows; R15 instead reconstructs **current available user-selected year-1 gas/Brent futures** from frozen `candidate_inputs_long.csv` through their publication rules at each origin. It omits that extra shift and saves source period/date/cutoff per observation. No exact constant-maturity or Refinitiv identity claim is made. This clarification is declared before any empirical model fit.

Scientific context: Stock and Watson's [Core Inflation and Trend Inflation](https://www.nber.org/papers/w21282) motivates separating persistent and transitory sectoral signals, but R15 is a small fixed-variance approximation, not their multivariate stochastic-volatility estimator. The [CNB WP9/2026](https://www.cnb.cz/export/sites/cnb/en/economic-research/.galleries/research_publications/cnb_wp/cnbwp_2026_09.pdf) motivates nonlinear forecast comparisons; the corrected residual forest here is an original experiment, not paper replication.

Pre-fit wide-block precision: use own state features + services/goods y/y and3-month changes + FX1/FX3 + the declared hard A6 rows. Do not repeat identical aliases such as unemployment and a6_11 or cost_26_now and a6_26, since duplicates would alter elastic-net shrinkage. Group ablations retain their derived IP/ULC features; the wide model uses the paper's raw transformed hard-variable set plus the explicitly listed extra signals.

## Fixed evaluation

- Outer origins remain the original 90 release-eve months, Feb2019-Jul2026. Generate earlier own-origin warmup for selection; never score warmup as test data. h0..12 output, h0 identical; headline annual compounding uses existing correct same-origin method. Store raw predictions before outcome/CNB joins.
- Primary scoreboard: common finite origin/horizon support for all new candidates and fixed STABLE_PIPELINE, INDEPENDENT_BRIDGE, STABLE_LOCAL_CORE controls. Also show pairwise support with pipeline, never mix sample definitions. Monthly core, cumulative log core, and headline annual RMSE/MAE/bias at every h; full, origin eras 2019-21/2022-23/2024+, recent targets. No war/error exclusions for promotion.
- Direction: forecast annual change from origin's latest known annual inflation, classify +/- when exceeding0.25pp and otherwise flat; evaluate on same paired samples at h3/6/9/12. Separately assess sign of adjacent predicted quarter-to-quarter changes when actual change exceeds0.25pp, and wrong-way material calls. Turning metrics are diagnostics, not tuned targets.
- CNB: same report-date clock and separate latest existing snapshot before CNB data cutoff, all common forecast quarters from2022 onward; quarterly average annual CPI, same support for each paired comparison. Keep repeated/overlapping quarters visible. Compare model-CNB deviation with realised-CNB error, require .15pp absolute-error gain for a material improvement and report material deteriorations. No choosing the clock that wins.
- Stability: revisions between adjacent origins at matched target months, correction sizes, selected hyperparameters and coefficient/source-group diagnostics; 12-origin moving-block bootstrap for paired MSE differences. Economic scenarios are explanatory conditional exercises, not evidence a model anticipated an unforeseeable shock.
- Underlying-turn diagnostic, fixed before the full run: for each origin, form four h1:3/4:6/7:9/10:12 average log-core rates after subtracting that origin's saved seasonal factors, then annualize by12. Material changes exceed0.5pp annualized; a local peak/trough at band2/3 requires two opposite material adjacent changes. Report predicted/actual turns, exact-band hits, misses and false turns, separately from headline base-effect direction. This diagnostic does not select hyperparameters or establish CNB core-turn superiority without CNB core paths.
- Provide an interactive local CNB-round replay artifact including the new models and controls, and transparent score/coverage tables. No live new-origin claim without a complete current data calendar.
