# CZK Cpi Forecasting - Latest models

Inflation path research, R14 and R14B · 9 September 2026

We have improved several recent path forecasts, but we have not established a
model that consistently beats the existing reference across regimes or matches
professional one-year forecasts. The most useful result is a clearer diagnosis:
the model needs better handling of inflation deceleration, food transmission and
regulated-price changes. Increasing model complexity alone did not solve these.

This round sourced public data, implemented and backtested new food, fuel and
core models, reconstructed a dated professional-survey benchmark, and independently
checked the calculations. The existing nowcast and operating forecast formulas
are unchanged. All new paths are independent of surveys and expectations.

## What the main results mean

RMSE measures typical error while giving larger misses more weight. Every number
below is in percentage points of annual Czech CPI inflation, unless stated
otherwise. Lower is better. A forecast of 3% against an outcome of 2% has a one
percentage point error. These are path forecasts, not the next-release surprise
capture scores used to choose nowcast challengers.

The original monthly roster has 90 origins, February 2019 through July 2026.
Each uses the saved release-eve clock and forecasts h0 through h12. Outcomes end
in July 2026. Consequently, the last scored h12 origin is July 2025: a saved July
2026 path is a historical-origin forecast with an unknown July 2027 outcome.
Annual outcomes are compounded from the frozen headline history at its supplied
precision. This path benchmark is distinct from the first-release/flash versus
release-consensus nowcast evaluation, which this round did not change.

| Independent path | h6: origins since 2024, N25 | h12: origins since 2024, N19 | h12: targets since 2024, N31 | h12: full common sample, N75 |
|---|---:|---:|---:|---:|
| Existing reference | 0.678 | 1.347 | 1.892 | 5.395 |
| Food + fuel update | 0.660 | 1.210 | 1.686 | 5.418 |
| Same update + recent core trend | **0.467** | **0.708** | 2.619 | 5.397 |
| Same update + longer-history core regression | 0.570 | 0.906 | 2.208 | 5.478 |
| Same update + longer-history core gap regression | 0.548 | 0.927 | 2.729 | 5.582 |

The two recent windows answer different questions. **Origins since 2024** tests
forecasts made after the large inflation shock. **Targets since 2024** also
includes forecasts made in 2023 for the subsequent disinflation. The simple
recent-core model looks excellent in the first window and weak in the second.
Reporting only the 0.708 would give a misleading impression of general skill.

The food-and-fuel update is less dramatic but improves both recent h12 windows.
Its full-sample result is essentially unchanged, slightly worse. None of the
four new combined paths is an unequivocal full-history winner.

Recent h12 gains have negative paired squared-error differences with block-
bootstrap intervals excluding zero. However, 19 overlapping monthly origins do
not provide 19 independent years of evidence. These histories have been examined
repeatedly, and R14B was explicitly designed after seeing R14. These intervals
describe conditional historical uncertainty; they do not correct for research
selection or certify prospective performance.

Evidence: `output/research_r14b/integration/summary.csv`,
`paired_uncertainty.csv`, `coverage.csv` and the release-by-release forecasts.
The comparison graphic is `output/research_r14/review/path_comparison.png`.

## The survey and CNB comparisons are now better specified

The stored FMIE table has one-year and three-year forecasts, not a six-month CPI
forecast. Its month labels are not publication timestamps. We therefore checked
24 actual CNB survey PDFs, August 2023 through July 2025, extracted their printed
issue dates and used the published one-decimal forecasts. We rebuilt our paths
at 00:00 Prague on the day after each printed document date.

This is a documented reconstruction, not proof of the exact website posting
time or the information cutoff used by survey respondents. Some reports were
issued in the following month. The code keeps the survey's reference month and
target month, rather than silently changing a twelve-month target into eleven
or thirteen months. The 24 realised targets run August 2024 through July 2026.

| One-year forecast at reconstructed report availability, N24 | RMSE | Mean error |
|---|---:|---:|
| Existing independent reference | 1.325 | +0.697 |
| Food + fuel update | 1.204 | +0.379 |
| Update + recent core trend | **0.976** | +0.672 |
| Update + longer-history core regression | 0.986 | +0.711 |
| Update + longer-history core gap regression | 1.186 | +0.936 |
| Published FMIE one-year mean | **0.410** | +0.013 |

The improvement is real on this panel, but the gap to the survey remains large.
No survey value enters a predictor, parameter estimate, state or forecast
combination. Survey values are joined only after predictions are written.

At h12 the annual forecast is exactly the compounded product of h1 through h12.
It excludes h0. We tested this at every report clock by replacing h0 with -50,
zero and +100: all future block contributions and h12 predictions were identical.
Independent poisoning tests also checked future observations and expectations.

For CNB quarterly reports, the target is the average of the three monthly annual
inflation rates in each quarter, not annual-average inflation for a calendar
year. The comparison uses our latest saved path preceding each report date.
These paths are a median eight days old, at most thirty days old. This is an
issue-vintage benchmark, not perfectly matched internal information sets.

| CNB comparison | Existing reference | Food + fuel | + Recent core trend | + Longer-history core | CNB |
|---|---:|---:|---:|---:|---:|
| Reports since 2024: 34 pairs, 10 distinct quarters | 0.590 | 0.598 | **0.402** | 0.512 | **0.372** |
| All reports: 66 pairs, 18 distinct quarters | 2.362 | 2.361 | 2.339 | 2.280 | 2.295 |

The recent trend model is close to CNB on this particular quarterly panel. This
does not contradict its weaker one-year FMIE result: the horizons, forecast dates,
targets and sample differ. Nor does the longer-history model's slightly lower
all-report RMSE prove superiority: its MAE is 1.409 versus CNB's 1.061, and the
observations overlap heavily.

Agreement with CNB is a useful economic cross-check. It is not the selection
objective. A forecast can be sensible yet disagree with CNB; both can also miss
the same shock. We must score realised outcomes, explain disagreements through
components and assumptions, and evaluate revisions as new information arrives.

Evidence: `output/research_r14/survey/`, the 24 raw PDFs under
`data/research_r14/benchmarks/`, and the integration `cnb_*` tables.

## What we built and what we learned

### Food: model the cost chain, but control persistence

The new food inputs are a fixed geometric basket of Czech farmgate wheat, milk,
pig and chicken prices, domestic food-manufacturing producer prices, and food
CPI. Each observation has an explicit eligibility rule. No retailer scraping
or future producer prices enter the forecasts. The fitted common history starts
in 2015; upstream variables follow their own model-generated future paths.

The initial model was a small Bayesian vector autoregression in log price
levels, with twelve lags and strong shrinkage toward a random walk. This follows
the economic idea that costs pass through farmgate prices, processing and retail.
It did **not** impose a fixed farmer-to-consumer price ratio.

That model failed an important stress test. At the June 2022 origin it forecast
about **295% cumulative food inflation over the following year**, against about
12% realised. Its fitted dynamics were explosive. This was not missing data or
a compounding bug, and the forecast has been preserved rather than clipped away.
The original R14 combinations that use it are rejected.

R14B instead models monthly log changes around calendar-month means, uses six
lags and up to 96 training months, and shrinks lag coefficients toward zero.
There is an explicit stability bound of 0.98 on the dynamic roots; none of the
180 fitted primary/control models required the contraction because the estimated
roots were already below it. The June 2022 food forecast became 10.7%, compared
with 12.0% realised and the original seasonal bridge's 15.0%.

The stable cost-chain food model improves recent food forecasts, but its own-food
autoregressive control is competitive and sometimes better. We have not proved
that the farmgate/PPI variables add robust incremental value. This is a modest
improvement with plausible structure, not a solved food model.

An official food CPI history back to 1995 was retrieved and checked against the
overlap. It has not been silently spliced into these results. The joint upstream
history remains the bottleneck; extending compatible farmgate and PPI histories
is a useful next data task.

### Fuel: explicit pump transmission improves the short end

We retrieved the European Commission's Czech weekly petrol and diesel prices
with and without tax, EIA daily Brent spot prices, and CNB daily exchange rates.
The pipeline converts dollar oil into koruna per litre, estimates separate weekly
petrol and diesel responses, and then aggregates their monthly price relatives.
The official, publication-gated fuel weights are preserved. No futures are used.

Unknown future oil and exchange-rate values are held at their latest eligible
observations. This is an explicit scenario, not a claim that we can predict oil.
A simpler comparator holds the latest observed pump prices constant; it still
captures carry from prices already observed partway through the month.

The source audit found discrepancies between reported gross prices, net prices
and the statutory excise series. Using those fields literally would create an
artificial price jump at the forecast seam. We therefore carry the observed
effective tax/reconciliation wedge, keep the statutory discrepancy visible, and
do not label the effective wedge as pure excise tax.

The weekly error-correction model improves h1 headline RMSE from 0.911 to 0.897
on its full paired panel. At h12 it does not beat the reference over the full
history. Some recent headline gains mostly reflect fuel errors offsetting errors
elsewhere. The combined R14B paths therefore use the transparent constant-pump
scenario; the estimated fuel model remains a near-term research challenger.

### Core: better history helped more than a larger forest

Six core variants forecast four three-month bands. They use core inflation
momentum, import-price changes, exchange-rate changes and calendar effects.
Seasonality, scaling and training targets are reconstructed using only the
information eligible at each origin. The alternatives include a recent-trend
control, level and gap ridge regressions, an adaptive ridge, and two forests.

The adaptive model chooses among six fixed penalty/window combinations using
only previously matured sequential forecast errors. Other forest and food/fuel
parameters were fixed in advance. This is not a search over thousands of
configurations evaluated on the final test sample.

An audit found that, despite core data beginning in 2007, missing import-price
history left usable original regression states beginning only in March 2016.
We retrieved the official older series: all 137 overlapping frozen observations
matched to numerical precision. We filled exactly 84 missing historical cells,
changed no finite existing cells, and applied a conservative source-month-plus-
three availability rule. The earliest usable state moved to January 2010 and
the number of states rose from 125 to 199.

On the same 19 recent h12 origins, the standalone level-ridge headline error fell
from 1.727 to 1.128; its core cumulative-log error fell from 1.409 to 0.589. The
improvement therefore includes a real gain in the predicted core component.
However, the simple current-trend control still did better in this recent window.
The longer history did not improve every forest or every disinflation panel.

The limitation is economic as well as statistical. A model that carries the
recent twelve-month core trend forward follows moderate persistent inflation
quite well, but can carry a temporary surge forward for too long. At the January
2023 origin, the combined local-core path forecast 8.92% for January 2024 against
2.32% realised. An exact replacement diagnostic attributes a 5.55 percentage
point marginal error to future core in that case. This is the principal reason
the model cannot yet replace the reference across regimes.

## Where the remaining errors are

We separately measured errors in core, food, fuel, regulated prices and alcohol/
tobacco, then replaced one future component at a time with its realised value.
These perfect-information replacements are diagnostic upper bounds, never
predictors. Their gains are conditional and nonadditive because component errors
can offset one another and the headline annual calculation compounds exactly.

For the local-core combined model's recent h12 origins, headline RMSE is 0.708.
Perfect future food alone would reduce it to 0.449; perfect regulated prices to
0.452. Perfect core instead would raise it to 0.829, despite core's own forecast
error being much smaller than the reference's. That is evidence of offsetting
remaining errors, not a reason to deliberately make core worse.

Two examples show where further work should concentrate. For January 2026, the
January 2025-origin regulated forecast was +0.9% m/m against -0.9% realised: about
0.318 percentage points of single-month weighted headline error. In the July
2025-to-July 2026 path, missed food declines after November contributed a large
positive error. In contrast, the older 2023-to-2024 failures mainly require
better core deceleration dynamics.

Evidence: `output/research_r14b/attribution/` retains 27,000 component rows,
actual targets, coverage, exact annual replacement diagnostics and event tables.

## How I would organize the models now

| Role | Model | Decision |
|---|---|---|
| Next-release independent nowcast | Existing HARD_BASE, with existing Half/Full challengers | Unchanged; R14 is a path experiment |
| Path reference | INDEPENDENT_BRIDGE | Keep as the stable comparison |
| Conservative path challenger | STABLE_PIPELINE_R14B | Modest food/fuel update; improves both recent h12 windows |
| Current-regime path challenger | STABLE_LOCAL_CORE_R14B | Strong recent origins and CNB panel; weak after the inflation surge |
| Econometric path challenger | STABLE_LONG_CORE_R14B | Longer-history level ridge; useful comparison, not a proven replacement |
| Near-term fuel challenger | FUEL_ECM_R14 | Test for the short end; no established long-horizon advantage |
| Rejected research | Original food level VAR and its three combinations | Preserve evidence; exclude from an operating forecast |

The long-history gap model, adaptive models, forests and food-only controls
remain in the research tables. They need not crowd the daily operating display.
Do not average all models simply because they exist, or switch retrospectively
between them using realised inflation. Any blend or regime rule must be declared
and selected with eligible past data, then frozen prospectively.

## The next improvements I recommend

**First, distinguish persistent core inflation from temporary pressure.** Test
a compact state-space model with a slowly changing underlying trend, a mean-
reverting cost-pressure component and deterministic seasonality. Imports and FX
should affect the temporary component through distributed lags. An alternative
is a small error-correction model with a separately estimated long-run core
mean. The purpose is to retain the local model's responsiveness without carrying
2022-type inflation into the following year. Estimate the underlying mean using
only the training sample; do not impose the latest survey or CNB forecast as the
answer. The CNB's 2% headline target may define a labelled long-run scenario,
but it is not automatically the correct equilibrium rate for the core basket.

**Second, make regulated prices a bill-and-policy forecast.** Source dated
supplier price lists, ERU network-charge decisions, tax changes, caps and subsidy
start/expiry events. Model the distribution of fixed and floating contracts and
reset timing, with ranges where coverage is uncertain. A broad regulated
seasonal median cannot reliably handle a transition from price increases to
price cuts. Only announcements known at the origin may affect its forecast.
Better accounting will not make an unannounced future policy change predictable.

**Third, extend and simplify the food pipeline before adding many predictors.**
Complete compatible older farmgate and food-PPI series; compare the stable
pipeline with an equally trained own-food control. Then test a small number of
separate grain/bread, dairy and meat cost chains with pooled coefficients.
Seasonal fresh-food shocks should not be forced to obey the same persistence
as processed food. Add import or energy costs only in prespecified ablations.

**Fourth, add a genuinely macro core challenger once these controls are fixed.**
A small shrinkage system using wages, unemployment/labour tightness, domestic
demand and external costs is more defensible than a very wide forest on a short
effective sample. Quarterly variables need their actual release clocks and
ragged-edge treatment. Earlier failed labour/category experiments remain relevant:
more economic detail does not automatically create forecast information.

**Finally, make the output a conditional path plus uncertainty.** Keep a central
independent path, show food/energy/FX and policy assumptions, and provide explicit
alternative scenarios. Estimate joint future component errors so monthly and
annual intervals respect serial and cross-component correlation. Evaluate bias,
MAE/RMSE, turning points and calibrated interval/quantile scores, including
eighteen-to-twenty-four-month holdout blocks when enough history is available.
Do not treat independently sampled monthly errors as a credible annual fan.

These are proposed next experiments, not results already established in R14.
The biggest immediate benefit is likely to come from better persistence and
policy accounting, rather than a much larger parameter search.

## Research sources and why they matter

The [CNB's 2026 machine-learning paper](https://www.cnb.cz/export/sites/cnb/en/economic-research/.galleries/research_publications/cnb_wp/cnbwp_2026_09.pdf)
motivates adaptive forecast combinations, while explicitly discussing the
difficulty trees have extrapolating an unprecedented inflation surge. Its
forecast target differs from our compounded twelve-month path, so its rankings
cannot simply be imported.

The [Bank of England's blockwise inflation study](https://www.bankofengland.co.uk/working-paper/2025/blockwise-boosted-inflation-non-linear-determinants-of-inflation-using-machine-learning)
motivates grouping predictors by economic mechanism. Its empirical treatment
of publication delays and revisions is less strict than the objective here;
our source-clock tests are therefore essential.

The [CNB's food-price analysis](https://www.cnb.cz/en/monetary-policy/inflation-reports/boxes-and-annexes-contained-in-inflation-reports/What-drives-food-prices/)
and [ECB Working Paper 1168](https://www.ecb.europa.eu/pub/pdf/scpwps/ecbwp1168.pdf)
support testing domestic production chains and transmission lags. They do not
justify an unstable price-level system or a fixed retail margin.

The [CNB's retail-fuel decomposition](https://www.cnb.cz/en/monetary-policy/inflation-reports/boxes-and-annexes-contained-in-inflation-reports/Factors-affecting-retail-fuel-prices),
[European Commission Oil Bulletin](https://energy.ec.europa.eu/data-and-analysis/weekly-oil-bulletin_en),
[EIA spot series](https://www.eia.gov/dnav/pet/hist_xls/RBRTEd.xls) and
[CNB fixing documentation](https://www.cnb.cz/en/faq/Format-of-the-foreign-exchange-market-rates/)
underpin the new fuel data and units. The saved raw files, retrieval metadata
and manifests permit inspection without downloading revised histories.

## Audit and replication status

The R9-R14 independent-model regression suite passed **485 tests**, with two
existing X13 warnings in inherited tests. Independent numerical checks reproduced
core fits, mature-error selection, monthly reconstructions, annual products,
combined scores, uncertainty calculations and professional benchmark joins.

Corrections made during this work include a historical-state JSON month-key
reload issue, stale combined fallback/convergence flags, incomplete hash
dependencies, and an initial evaluation join that included undeclared older
origins. They were fixed with explicit tests. None was hidden by changing the
economic specification or selecting a different score window.

The original and extended core, both food models, fuel model, integrations,
history comparison, survey reconstruction and attribution have offline replay
paths. The external delivery receipt records the final fresh extracted-copy
checks, package hashes and original-source preservation. Reproduction depends
on the supplied package versions and the Census X13 binary identity where used.

The evidence is still pseudo-real-time: many historical values are latest
vintages with reconstructed publication rules. EC pump revisions are visible;
announcement histories contain previously disclosed reconstructed judgments.
The report-date survey clock is also reconstructed. A successful offline replay
proves reproducibility, not that every historical input was the exact vintage
available then. All candidate paths remain research-only pending a frozen
prospective run and hardened live data refresh.

R14 declarations were committed before their fits. R14B was an openly
outcome-informed follow-up: a3740fe fixed stable food, 08d6843 added its dated
survey comparison, and 709d4b3 fixed the verified import extension and additional
combinations. Failed R14 results remain beside the follow-up results.
